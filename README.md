# pgmfinder (동업계 셀럽PGM 품목 자동 취합)

CJ온스타일 / GS샵 / 롯데홈쇼핑의 주요 셀럽 프로그램(강주은·김창옥·김신영·최화정·최유라·백지연) 방송 품목을 자동으로 모아서 보여주는 프로그램이에요. 전문 지식 없이도 아래 순서만 따라 하면 됩니다.

1. 맨 처음 딱 한 번만 하면 되는 준비: 파이썬(Python) 설치

이미 컴퓨터에 파이썬이 설치되어 있다면 이 단계는 건너뛰고 2. 실행하기로 가세요.

Windows 사용자
인터넷 브라우저에서 python.org/downloads 로 접속해요.
가운데에 있는 노란색 "Download Python" 버튼을 눌러요. (자동으로 최신 버전이 다운로드돼요)
다운로드된 설치 파일을 더블클릭해서 열어요.
아주 중요: 설치 화면 맨 아래에 있는 "Add python.exe to PATH" (또는 "Add Python to PATH") 체크박스를 반드시 체크해요. 이걸 안 하면 나중에 실행이 안 될 수 있어요.
"Install Now" 버튼을 눌러서 설치를 끝내요.
Mac 사용자
python.org/downloads 로 접속해서 "Download Python" 버튼을 눌러요.
다운로드된 .pkg 파일을 더블클릭하고, 화면 안내대로 "계속/동의/설치"를 눌러요.

2. 실행하기
이 저장소 페이지에서 초록색 "Code" 버튼 → "Download ZIP" 을 눌러 내려받아요. (또는 pgm.py 파일만 따로 받아도 돼요)
다운로드된 폴더(또는 zip을 풀어놓은 폴더) 안에 있는 pgm.py 파일을 찾아요.
그 파일을 더블클릭해요.
검은색 창(터미널)이 잠깐 떴다가, 잠시 후 메모장이 자동으로 열리면서 이번 주/다음 주 취합 결과가 보여요. 이게 끝이에요!

결과는 메모장 파일로도 같은 폴더에 저장돼요. 파일 이름은 동업계_PGM_모니터링_날짜.txt 형식이에요. 나중에 다시 보고 싶으면 그 파일을 열면 됩니다.

더블클릭해도 아무것도 안 열릴 때
파일을 마우스 오른쪽 버튼으로 클릭 → "연결 프로그램" → "Python" 을 선택해서 열어보세요.
그래도 안 되면, 1단계(파이썬 설치)에서 "Add python.exe to PATH" 체크를 빼먹었을 가능성이 높아요. 파이썬을 삭제하고 다시 설치하면서 그 체크박스를 꼭 체크해주세요.
인터넷이 연결되어 있어야 정상적으로 데이터를 가져올 수 있어요.

3. 자주 묻는 질문

Q. 특정 날짜 기준으로 보고 싶어요. 검은 창(명령 프롬프트)을 열고 아래처럼 입력하면 돼요.

python pgm.py --date 2026-08-24

Q. 이번 주 것만 보고 싶어요.

python pgm.py --weeks this

Q. "(데이터 미공개)"라고 나와요. 오류인가요? 오류가 아니에요. 원본 사이트(hdmzp.github.io)에 아직 그 회차 정보가 올라오지 않은 경우예요. 시간이 지나면 채워집니다.
